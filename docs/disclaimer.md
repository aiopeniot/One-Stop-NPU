# 公开资料合规声明 (Public Information & Compliance Statement)

本项目由开源社区发起并维护，旨在为 AI 部署与硬件系统工程师提供公开的技术知识索引。我们严格遵守以下原则：

### 1. 资料合法性准则
- **来源可追溯**：仓库内所有技术解析与参数，均需附带公开发布的官方 URL、已公开的技术白皮书、专利公开文本、开源驱动代码库或顶级学术会议论文链接。
- **杜绝保密物料**：严禁提交任何受 NDA（Non-Disclosure Agreement）保护的内部文档、邮件往来、未公开勘误表（Erratum）或内部基准数据。
- **实测数据声明**：所有性能监控与基准测试数据，均基于公开市售硬件（Retail HW）和公开发布的软件版本（GA/Public Beta）实测得出。

### 2. 首发公开数据源参考 (Intel NPU)
- **开源驱动代码**：[intel/linux-npu-driver](https://github.com/intel/linux-npu-driver)
- **官方推理引擎**：[openvinotoolkit/openvino](https://github.com/openvinotoolkit/openvino)
- **官方技术规格文档**：Intel Ark 公开产品规格表及 Architecture Day 公开发布 Slide

### 3. 内容异议与下架流程
若任何厂商或权利人认为本仓库收录的内容涉及非公开信息或存在版权争议，请在 GitHub Issues 提交“Compliance Notice”或发送邮件，维护团队将在 24 小时内完成核查与下架处理。
